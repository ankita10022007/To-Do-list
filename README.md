# To-Do List CLI App

A simple command-line To-Do List application built using Python.  
The application allows users to add, view, remove, and save tasks.

## Features

- Add new tasks
- View all tasks with task numbers
- Remove tasks by their number
- Save tasks to a text file
- Automatically load saved tasks when the program starts
- Simple and easy-to-use command-line interface
- Uses functions to organize different features

## Technologies Used

- Python 3
- Text file (`tasks.txt`) for storing tasks
